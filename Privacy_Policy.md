## 8. Security / الأمان

We implement industry-standard security measures:

- **Encryption in transit**: TLS 1.3 for all connections
- **Encryption at rest**: AES-256 for sensitive data (rental contracts, ID copies)
- **Access control**: Role-based access; principle of least privilege
- **Audit logs**: Immutable logs of all data access (kept 7 years)
- **Backup**: 3-2-1 strategy (3 copies, 2 media types, 1 offsite)
- **Regular security reviews**: Quarterly internal + annual external pen-test
- **Multi-factor authentication**: Required for all admin access
- **Breach notification**: Within 72 hours per GDPR Article 33
