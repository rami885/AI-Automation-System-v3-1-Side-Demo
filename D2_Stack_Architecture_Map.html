L9 · COST GOVERNANCE — NEW IN V3

Cost Governance — حماية التكلفة

Circuit breaker · budget per agent · auto-downgrade Opus→Sonnet→Haiku

+
Circuit Breaker 100% BLOCK
يقطع الـ agent تلقائياً لو تعدّى ميزانيته الشهرية. لا يُستأنف إلا بإذن رامي.
Budget Per Agent €/MONTH
shop=€50 · comms=€50 · finance=€40 · rental=€30 · repair=€30 · orchestrator=€80.
Auto-Downgrade SMART
T1 reads = Haiku 4.5 (أرخص) · T2/T3 = Sonnet · GDPR/compliance = Opus 4.7 فقط.
Alerts 50/80/100% 3-STAGE
50% = info notification · 80% = warning + slow-down · 100% = block + escalate.
Prompt Caching 1HR TTL
system prompts cached aggressively. ~40% توفير على المكالمات المتكررة.
DESIGN PRINCIPLES
1. Orchestrator لا ينفّذ — يوزّع فقط
2. كل sub-agent له نطاق ضيق وأدوات محدودة
3. T3+ يحتاج موافقة بشرية صريحة
4. Banking ممنوع — حتى مع موافقة
5. كل قرار في Audit Trail
6. Cost circuit breaker يعمل قبل أي ضرر مالي
