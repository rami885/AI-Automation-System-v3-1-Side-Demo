٢) من يرى ماذا — حدود الثقة (Trust Boundary)

٣) الحزمة التقنية المعتمدة (online · تملك بياناتك)

VPS واحد أونلاين = وصول من أي مكان + البيانات تبقى عندك. لا سحابة مُدارة تأخذ بياناتك.

الاستضافة

  • Hostinger VPS — أونلاين، تملّك كامل
  • Cloudflare (DNS + TLS + WAF) في المقدمة

الهوية + البيانات

  • Supabase self-hosted
  • Auth + Postgres + Storage + RLS + Audit

واجهة المحادثة

  • الآن: LibreChat (جاهزة)
  • لاحقًا: Next.js مخصص + PWA

القلب

  • Backend stateless + Docker
  • Channel Adapter + Policy Engine
  • Claude Code Orchestration
