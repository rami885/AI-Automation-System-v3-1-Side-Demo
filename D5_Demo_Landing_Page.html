الحل

نظام واحد. خمس وكلاء. عمل ذكي 24/7.

AI Automation System هو إطار عمل modular يضع خمسة وكلاء AI متخصصين على رأس الأنظمة الموجودة عندك (WooCommerce، WhatsApp، POS). كل وكيل مسؤول عن مجال محدد، يعمل تحت إشراف orchestrator مركزي يضمن السلامة والتكلفة.

AGENT 01

Shop Agent

يدير المخزون، الأسعار، والموردين. ينبّهك قبل نفاد المخزون بأسبوعين.

  • تحديث أسعار مع موافقتك
  • تنبيهات المخزون التلقائية
  • مراقبة أسعار المنافسين
  • إدارة B2B pricing tiers
AGENT 02

Repair Agent

يدير تذاكر الصيانة، يتابع IMEI، ويرسل تحديثات للزبائن تلقائياً.

  • فتح تذاكر من WhatsApp مباشرة
  • تتبع حالة الإصلاح
  • تنبيهات الزبائن عند الجاهزية
  • إدارة الضمان
AGENT 03

Rental Agent

يحسب الإيجارات، يقسّم الفواتير المشتركة، ويذكّر المتأخرين عنك.

  • حساب utility split بدقة
  • تنبيهات انتهاء العقود
  • تذكيرات الدفع تلقائية
  • تتبع المستأجرين والإشغال
AGENT 04

Finance Agent

يجمّع المصاريف، يحسب VAT، ويولّد تقارير شهرية بنقرة واحدة.

  • تقارير VAT جاهزة
  • P&L شهري تلقائي
  • مطابقة بنكية
  • كشف حسابات للموردين
AGENT 05

Comms Agent

يرد على رسائل WhatsApp بصوت علامتك التجارية، ويصمّم بوستات سوشيال ميديا.

  • ردود WhatsApp مع قوالب معتمدة من Meta
  • مسوّدات بوستات Instagram/Facebook
  • إيميلات تسويقية
  • مراقبة المراجعات والتعليقات
CORE

Orchestrator

العقل المركزي. يوزّع المهام، يراقب التكلفة، يطلب موافقتك على القرارات الحساسة.

  • توزيع ذكي للمهام
  • طلب موافقة على T3+ actions
  • circuit breaker للتكاليف
  • audit log كامل

أسئلة شائعة

الأسئلة اللي يسألها أصحاب الأعمال قبل ما يبدأوا

هل بياناتي آمنة؟ والـ AI ما يخرّب شغلي؟
+
نعم. النظام مبني على 4 طبقات حماية: (1) Tool Tiers — كل أداة مصنّفة من T1 (قراءة فقط) إلى T4 (مدمّر) ولا يحدث تعديل بدون موافقتك. (2) GDPR Gate لأي بيانات شخصية. (3) Banking ممنوع كلياً — حتى لو طلبت. (4) Audit log كامل لكل قرار. وكل عميل في namespace منفصل، مستحيل تتسرب بيانات لعميل ثاني.
أنا عندي WordPress + WooCommerce — هل أحتاج أغيّر شي؟
+
لا. النظام مصمّم خصيصاً ليعمل فوق WordPress + WooCommerce + Elementor. نضيف 3-4 plugins (OpenPOS لو محتاج POS، RepairBuddy لو محتاج تذاكر صيانة) وندمج الـ AI فوقهم. ما نطلب منك تغيير platform أو هجرة بيانات.
كم تكلفة Claude AI الشهرية فعلياً؟
+
للعمل المتوسط (Pro tier): 80-200 EUR شهرياً. عندنا Layer 9 (Cost Governance) — circuit breaker يقطع الـ agents تلقائياً لو تجاوزوا الميزانية، و auto-downgrade من Opus لـ Sonnet لـ Haiku حسب نوع المهمة. تنبيهات على 50% / 80% / 100%. ما في مفاجآت في فواتير API.
متى أرى أول نتيجة فعلية؟
+
الأسبوع 3 — أوّل agent يبدأ يشتغل في إنتاجك الفعلي (عادة Comms أو Shop). بعد شهر كامل تكون كل الـ 5 agents شغّالين. خلال 90 يوم نقيس KPIs محددة معك في جلسة الاكتشاف.
ماذا لو فشل النظام أو قررت إيقافه؟
+
لا lock-in. كل بياناتك تبقى عندك (في WordPress + Postgres). الـ AI agents فقط طبقة فوق. لو وقفت الاشتراك، الأنظمة الأساسية (متجرك، POS، إلخ) تستمر تعمل بدون مشاكل. تأخذ نسخة من كل الـ skills والـ configurations.
هل النظام بالعربي والإنجليزي؟
+
نعم، AR + EN في الإصدار الأول. اليوناني (EL) قادم في الإصدار 3.5. كل الواجهات RTL-aware، والـ AI agents يفهمون ويردون بالعربية والإنجليزية حسب لغة الزبون. brand voice قابل للتخصيص لكل لغة.
