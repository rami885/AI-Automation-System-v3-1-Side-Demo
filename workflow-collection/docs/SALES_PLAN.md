# خطة البيع (Sales Plan)

## 1. ما الذي تبيعه فعلياً؟
الملفات الخام مجانية على GitHub. المشتري يدفع مقابل:
1. **التنظيف والتنظيم**: 3,304 ورك فلو بدون تكرار، بدون أسرار، مصنّفة في 16 كاتيجوري، بأسماء مفهومة.
2. **الكتالوج القابل للبحث**: `catalog/index.html` + CSV.
3. **أدلة الإعداد** للـ premium (591 ورك فلو AI).
4. **التحديثات**: الـ pipeline يعيد البناء بأمر واحد، فتبيع "lifetime updates" بصدق.
5. **الأصلي**: الورك فلوز اللي بنيتها أنت (83 على n8n الخاص بك) بعد تعميمها وتنظيفها. هذه الطبقة الوحيدة التي لا يملكها أحد غيرك وتبرر سعراً أعلى.

## 5. صفحة المنتج (العناصر الإلزامية)
- عنوان: "3,300+ Clean n8n Workflows — 16 Categories, 700+ AI Agents, Zero Duplicates, Zero Leaked Keys"
- 3 صور: شبكة الكاتيجوريز، سكرين شوت الكتالوج، مثال ورك فلو AI مفتوح في n8n.
- جدول الكاتيجوريز مع الأعداد (من `catalog/stats.json`).
- ماذا يميزك: deduped، sanitized، provenance، updates، Arabic support.
- الترخيص للمشتري: استخدام شخصي وتجاري، ممنوع إعادة البيع أو التوزيع.
- FAQ: هل يعمل مع n8n cloud؟ (نعم) هل أحتاج API keys؟ (نعم لكل خدمة) هل في تحديثات؟ (نعم)
- Attribution: "Built on MIT/CC-BY community work, see THIRD_PARTY_LICENSES".
