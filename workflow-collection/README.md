# n8n Workflow Collection — مجموعة ورك فلوز جاهزة للبيع

مجموعة منظّمة، منظّفة، ومصنّفة من ورك فلوز n8n مجمّعة من أكبر المصادر المفتوحة المرخّصة، مع pipeline يعيد بناءها بأمر واحد، وكتالوج قابل للبحث، وخطة بيع.

## هيكل المجلد

```
workflow-collection/
├── README.md                 ← هذا الملف
├── scripts/
│   ├── sources.json          ← المصادر + حالة الترخيص لكل مصدر
│   └── collect.py            ← الـ pipeline كاملاً (Python 3، بدون مكتبات خارجية)
├── catalog/
│   ├── index.html            ← متصفح الكتالوج (بحث/فلترة) للمعاينة والبيع
│   ├── catalog.json / .csv   ← كل ورك فلو مع التصنيف والجودة والمصدر
│   ├── CATALOG.md            ← قائمة قابلة للقراءة مجمّعة بالكاتيجوري
│   ├── stats.json            ← الإحصائيات
│   ├── review_report.md      ← تقرير المراجعة (أسرار، تحت الحد، تكرارات قريبة)

└── docs/
    ├── SOURCES.md            ← المصادر وتراخيصها ومصادر مرشّحة
    ├── LICENSING.md          ← ماذا يجوز بيعه وما يلزم إرفاقه
    ├── CATEGORIES.md         ← الكاتيجوريز الـ 16 والطبقات ونظام التقييم
    ├── REVIEW_CHECKLIST.md   ← قائمة المراجعة البشرية
    ├── SALES_PLAN.md         ← التسعير، المنصات، صفحة المنتج، التسويق
    └── LOCAL_PROMPT.md       ← البرومبت الجاهز لتشغيل بقية العمل على جهازك
```

## كيف تعيد البناء

```bash
cd workflow-collection
python3 scripts/collect.py --fetch          # يستنسخ المصادر ويبني كل شيء (≈1 دقيقة بعد الاستنساخ)
python3 scripts/collect.py --min-score 60   # بوابة جودة أشد
python3 scripts/collect.py --extra ~/my-n8n-exports   # يضيف ورك فلوزك الأصلية كـ license=OWN
python3 -m http.server -d catalog 8080      # ثم افتح http://localhost:8080 لتصفح الكتالوج
```

## ماذا يفعل الـ pipeline لكل ملف

1. يتحقق أنه تصدير n8n حقيقي (nodes + connections).
2. يحسب بصمة المحتوى ويحذف التكرارات المطابقة عبر كل المصادر، ويحتفظ بالنسخة المرخّصة.
3. يمسح الأسرار (OpenAI، Anthropic، Slack، Discord webhooks، Telegram bot tokens، AWS، Stripe، JWT، كلمات سر…) ويستبدلها بـ `<<REDACTED-REPLACE-WITH-YOUR-OWN>>`.
4. يحذف `pinData` ومعرّفات الـ instance والـ webhook والـ credential ويضبط `active=false`.
5. يستخرج التكاملات ونوع الـ trigger وهل يستخدم AI.
6. يصنّفه في واحدة من 16 كاتيجوري (الأنواع تزن 3، كلمات الاسم تزن 2).
7. يعطيه درجة جودة 0-100 ويحدد الطبقة (premium / standard / review-only / rights-needed).
8. يولّد اسماً وصفياً إذا كان الاسم الأصلي عامّاً مثل "My workflow" أو "Httprequest Workflow" ويضعه في قائمة إعادة التسمية.
9. يبعد النسخ المتكررة بنفس الاسم والهيكل والقوالب الهيكلية المصطنعة.
10. يكتب الملف المنظّف مع `meta.collectionProvenance` ويبني الكتالوج والتقارير.

## ملاحظة قانونية مختصرة

يُباع فقط ما مصدره MIT أو CC BY (مع ذكر المصدر). المصادر بدون ترخيص تُجمع للمراجعة فقط ولا تُرفع إلى git. قوالب n8n.io لا تُضمَّن. التفاصيل في `docs/LICENSING.md`.

## الخطوة التالية

افتح `docs/LOCAL_PROMPT.md`، انسخ البرومبت إلى Claude على جهازك، وستُنفَّذ المراحل الست (توسعة المصادر، إدخال ورك فلوزك الأصلية، إعادة التسمية بالـ LLM، اختبار الاستيراد على n8n محلي، التغليف في zip، نصوص صفحات البيع).
